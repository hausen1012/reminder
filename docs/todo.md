# 功能规划与待办清单 (TODO)

本文档整理自系统现状评估与潜在功能扩展规划，按模块分类并区分建议优先级。

---

## 一、 提醒与调度核心

- [ ] **稍后提醒 (Snooze / 延期)** `高`
  - 触发后或在 `/c/:token` 确认页提供稍后提醒选项（如 10 分钟、30 分钟、1 小时后再次触发）。
  - 支持在 Web 控制台对未处理提醒进行快捷延期。
- [ ] **标签与分类管理 (Tags / Categories)** `高`
  - 支持为提醒打上自定义标签或归类（如工作、生活、财务、健康）。
  - 列表与筛选工具栏增加标签过滤与聚合统计。
- [ ] **优先级标记 (Priority)** `中`
  - 增加优先级字段（低 / 普通 / 高 / 紧急），用于列表排序与不同通知渠道的样式强调。
- [ ] **提前预警 / 多阶提醒 (Advance Notice)** `中`
  - 同一提醒支持配置多个触发时机（例如会议前 15 分钟预警，到期时再次提醒；生日提前 3 天提醒）。
- [ ] **调度生命周期与归档管理** `中`
  - 周期提醒支持配置「结束时间」或「最大触发次数」，满足条件后自动终止。
  - 单次提醒触发后增加「已完成 / 归档」状态流转与自动隐藏选项。
- [ ] **法定节假日与调休识别** `低`
  - 引入法定节假日数据源，支持「仅工作日（跳过节假日，调休补班时触发）」等中国日历调度语义。
- [ ] **全局与通道免打扰时段 (Do Not Disturb)** `低`
  - 支持配置免打扰时间范围（例如夜间 23:00 - 08:00），期间触发的非紧急提醒延后或静默发送。

---

## 二、 通知渠道与投递策略

- [ ] **扩展主流推送渠道** `高`
  - **Gotify**：自托管推送服务支持。
  - **Discord**：Webhook 与 Bot 消息推送。
  - **Slack**：Incoming Webhooks / App 消息集成。
  - **Pushover**：移动设备高可靠推送。
  - **短信 / 语音**：对接阿里云、腾讯云或 Twilio 用于高优先级强提醒。
- [ ] **渠道失败降级与主备策略 (Fallback Channels)** `中`
  - 支持主备渠道链配置。首选渠道重试失败后，自动尝试备用渠道（如飞书失败转邮件或短信）。
- [ ] **消息模板与卡片自定义** `低`
  - 允许在 Web 控制台自定义各渠道的消息排版、卡片色彩和展示字段。

---

## 三、 日历与外部生态集成

- [ ] **iCalendar / Webcal 订阅 (.ics)** `高`
  - 提供安全 Token 保护的 Webcal 订阅 URL。
  - 允许系统日历（Apple Calendar、Google Calendar、Outlook）直接同步系统中的待办事件。
- [ ] **数据导入与导出** `中`
  - 支持以 JSON / CSV / ics 格式批量导入与导出提醒规则。
- [ ] **数据库备份与归档** `中`
  - Web 控制台提供一键导出 SQLite 数据库备份文件功能。
  - 支持配置定期备份并同步至本地目录或远程存储（如 WebDAV / S3）。

## 四、 前端与交互体验 (UI / UX)

- [ ] **日历视图 (Calendar View)** `高`
  - 增加月历 / 周历大盘视图，直观查看各日期的提醒分布与触发密度。
- [ ] **PWA (渐进式应用) 与 Web Push** `中`
  - 配置 `manifest.json` 与 Service Worker，支持桌面及移动端独立安装使用。
  - 支持浏览器原生 Web Push 消息推送。
- [ ] **国际化多语言支持 (i18n)** `低`
  - 界面与错误文案抽离为多语言资源包，补充英文界面支持。

## 五、 安全与运维管理

- [ ] **双因素认证 (2FA / TOTP)** `中`
  - 增加基于 TOTP 的二次认证（Google Authenticator、1Password 等），增强暴露于公网时的安全性。
- [ ] **活跃会话与登录管理** `低`
  - 支持查看当前活跃登录设备与 IP，提供一键注销指定或全部会话功能。
- [ ] **操作审计日志 (Audit Log)** `低`
  - 记录管理员对关键资源（提醒、通道密钥、系统时区、外部令牌等）的新增、修改与删除操作。

## 六、 AI 助手扩展

- [ ] **日程汇总与智能分析** `中`
  - 新增全局分析类工具，支持自然语言查询“总结本周所有提醒”或“分析近期未确认任务”。
