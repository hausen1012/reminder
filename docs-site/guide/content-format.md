# 内容格式与占位符

提醒的标题与正文支持三种格式，并可以在正文里写占位符，发送时替换成实际值。

## 三种内容格式

| 格式 | 说明 |
|---|---|
| `text` | 纯文本，默认值 |
| `markdown` | 富文本标记，各通道按自身能力渲染 |
| `html` | HTML 标签 |

格式只影响**正文**的呈现方式，标题始终按纯文本渲染。

### 各通道的适配方式

| 通道 | `text` | `markdown` | `html` |
|---|---|---|---|
| SMTP | `text/plain` | 转成 HTML 后发送 | 原样作为 `text/html` |
| 钉钉 | text 消息 | markdown 消息 | 剥掉标签后按 text |
| 企业微信 | text 消息 | markdown 消息 | 剥掉标签后按 text |
| Webhook | 原样 | 原样 | 原样 |
| 日志 | 原样 | 剥掉标记 | 剥掉标签 |

Webhook 不做任何转换，`{{content}}` 拿到什么就发什么，转换责任交给你的模板。

## 占位符

正文（以及标题、Webhook 模板）里可以写 `{{变量名}}`，发送前会被替换成实际值。

```
今天是 {{now_date}}（{{weekday}}），{{lunar_date}}。
提醒内容：{{content}}
```

渲染规则：

- 只做 `{{name}}` 的字符串替换，不支持表达式、条件、循环、函数调用
- 变量名只允许字母、数字、下划线和点号，前后可以有空白（`{{ now }}` 等价于 `{{now}}`）
- **未定义的占位符原样保留**，方便排查拼写错误
- 不做递归展开：变量值里若包含 `{{x}}`，不会被再次替换

完整的变量列表见[模板变量](/reference/variables)。

## 渲染顺序

一次触发时的渲染顺序是固定的：

1. 准备原子变量（时间、标题、内容、农历等）
2. 用这批变量渲染正文，展开其中的占位符
3. 把渲染后的正文写回 `content` 变量
4. 需要确认时注入 `confirm_url`
5. 用最终的变量渲染标题，以及 Webhook 的模板字段

因此 Webhook 模板里的 `{{content}}` 拿到的是**已经渲染过**的正文，不会出现占位符残留。

## 自动追加确认链接

如果提醒开启了「需要确认」，但正文里没有写 `{{confirm_url}}`，系统会自动在正文末尾追加确认链接，
并按内容格式选择呈现方式：

| 格式 | 追加内容 |
|---|---|
| `text` | `点击确认提醒：https://...` |
| `markdown` | `[点击确认提醒](https://...)` |
| `html` | `<a href="https://...">点击确认链接</a>` |

如果想自己控制链接位置与文案，就在正文里显式写 `{{confirm_url}}`，系统便不再追加。

详见[确认机制](/guide/confirmation)。
