# 项目介绍

Reminder 是一套自托管的个人提醒 / 通知系统。你把要做的事写进去，到点由系统通过你配置的渠道
把消息发给你；如果是需要确认的提醒，你点一下消息里的链接就完成闭环。

- 开源仓库：[github.com/hausen1012/reminder](https://github.com/hausen1012/reminder)
- 文档地址：[hausen1012.github.io/reminder](https://hausen1012.github.io/reminder/)

它面向的场景是「一个人或一个小组自己的提醒需求」，因此刻意做成**单进程 + 单文件 + 单数据库**：

- 前端构建产物直接嵌入 Go 二进制，部署只需要拷贝一个可执行文件
- 数据存在本地 SQLite 文件里，不需要额外安装数据库
- 内置登录认证，开箱即可对外提供服务

## 核心能力

| 能力 | 说明 |
|---|---|
| 调度 | 单次、周期（分 / 时 / 天 / 月 / 年）、Cron 表达式；公历与农历 |
| 通道 | SMTP 邮件、钉钉机器人、企业微信机器人、通用 Webhook、日志通道 |
| 内容格式 | 纯文本、Markdown、HTML，各通道按自身能力适配或降级 |
| 占位符 | 正文里可写 `{{now_date}}`、`{{lunar_date}}`、`{{confirm_url}}` 等，发送时渲染 |
| 确认机制 | 发送后附带一次性链接，未确认按配置自动重发 |
| 兜底补发 | 进程重启期间错过的触发会被补发，超窗口标记过期 |
| 日志 | 记录每次触发与每个通道的每次尝试，支持按条件查询与批量清理 |
| 外部 API | 用令牌调用接口程序化创建提醒，未指定通道时回退到令牌默认通道 |

## 明确不做的部分

为了让实现保持简单可维护，以下能力不在范围内：

- 多用户隔离（只有一个账号）
- 国际化
- 集群 / 多副本部署（SQLite + 内存调度器不支持）
- 数据导出 / 备份工具（直接备份 SQLite 文件即可）
- 复杂模板引擎（只做 `{{name}}` 字符串替换）
